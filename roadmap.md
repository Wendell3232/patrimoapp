# Roadmap

## Prioridade (pedido do usuário)
- [x] Onboarding guiado em 5 etapas (primeiro acesso)
- [x] Dashboard/Visão Geral: patrimônio contínuo, comparação com período anterior, cards Entradas/Despesas/Resultado, lançamentos do mês

## Base
- [x] Banco de dados + RLS por usuário
- [x] Login e-mail/senha (ver/ocultar) + Google
- [x] Dados de demonstração (botão opcional em Configurações)

## Módulos
- [x] Movimentações + ações rápidas (receita, despesa, transferência)
- [x] Contas
- [x] Cartões de crédito (parceladas, faturas)
- [x] Compromissos e calendário
- [x] Metas
- [x] Orçamentos com alertas 90% / 100%
- [x] Relatórios
- [x] Agente Financeiro (insights + pergunta em linguagem natural)
- [x] Notificações, Configurações, Perfil
- [x] Página de Planos (R$ 27,90/mês, R$ 97,90/ano)

## Pendências
- [ ] Cobrança real dos planos (precisa de meio de pagamento)
- [x] Pagamento de fatura de cartão (debitar conta) na tela de Cartões
- [x] Botão opcional "carregar dados de demonstração"
- [x] Aportes em metas, orçamentos por mês, avisos automáticos
- [x] Editar/arquivar contas e cartões, excluir metas/orçamentos com confirmação
- [x] Primeiros passos obrigatórios, renda mensal e barra inferior no celular
- [x] Cadastro ativa a conta na hora (sem e-mail de confirmação)
- [x] Retorno do login com Google em página própria (/auth-callback)
- [x] Rotinas internas do banco bloqueadas para visitantes não logados
- [ ] Domínio de e-mail próprio (necessário para e-mails com sua marca e recuperação de senha confiável)

- [x] Aplicar identidade TailGrids ao aplicativo inteiro
